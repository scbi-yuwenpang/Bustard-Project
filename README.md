# 07_Bustard Project

The **Bustard Project repository** is a shared workspace for organizing, developing, and maintaining the analytical workflows and technical resources used by the Bustard project team **@Smithsonian's National Zoo and Biological Conservation Institution**.

The repository was established to provide a **central and collaborative environment** where project members can maintain scripts, notebooks, protocols, GIS resources, and supporting documentation in a consistent and reproducible way. It is intended to connect the different technical and ecological components of the project while reducing duplication of code and facilitating collaboration among team members.

## Scope

The repository supports work across several complementary research areas, including:

* **Remote sensing and habitat mapping**
* **GIS and spatial analysis**
* **Ecological and vegetation studies**
* **Houbara bustard ecology and habitat assessment**
* **Vegetation cover and food availability analyses**
* **Human activity and anthropogenic pressure analyses**
* **Field-data processing and integration**
* **Development of reproducible analytical workflows**

Both **Python and R** scripts are maintained within the repository, together with Jupyter notebooks and other supporting materials where appropriate.

## Repository organization

The repository is organized into thematic folders corresponding to the main components of the Bustard Project. These currently include project notebooks, ecological studies, GIS resources, vegetation and food-availability studies, Houbara and human-activity datasets and protocols, and other supporting project materials.

As the project develops, the repository is intended to serve as the common location for:

* analytical scripts and reusable functions;
* data-processing and remote-sensing workflows;
* project-specific notebooks;
* GIS and spatial-analysis resources;
* field and ecological protocols;
* metadata and documentation;
* figures, tables, and intermediate analytical products where appropriate.

## Collaboration and reproducibility

A central objective of this repository is to ensure that analytical methods developed during the Bustard Project remain **transparent, reproducible, and accessible to the project team**.

Team members are encouraged to document analytical steps, use clear file and folder names, maintain reusable scripts rather than isolated local versions, and record important changes through Git and GitHub.

Because remote-sensing imagery, GIS datasets, photographs, and other project resources can be very large, the repository should primarily be used to maintain **code, workflows, metadata, documentation, and lightweight project resources**. Large datasets may be maintained in the appropriate project storage system, with their locations and processing procedures documented here.

## Project aim

Ultimately, this repository provides the technical framework for integrating **remote sensing, GIS, field ecology, and ecological analysis** within the Bustard Project and for maintaining a coherent analytical record as the project evolves.
